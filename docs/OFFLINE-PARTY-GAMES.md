# 开心盒：离线聚会玩法

本次只在 `ui/android-happybox-redesign` 开发。保留既有随机工具、音乐、账号、同步、设置、狼人杀、真心话大冒险、谁是卧底和海龟汤。按用户补充，取消屏幕选人，不增加入口。

## 模块

- `ui/party-core.js`：纯规则；数字炸弹范围与猜测验证、金额精度、双边流水和本地数据校验，可由 Node 独立测试。
- `ui/party-library.js`：随 APK 打包的猜词和任务分类题库，不依赖网络。猜词六类 195 词，任务三类 80 条；以后按分类追加即可。
- `ui/party-games.js`：共享生命周期、本地存储、数字炸弹、猜词、任务交接与真心话联动。
- `ui/party-score.js`：记分局、玩家管理、流水、修改、撤销、封存和删除。
- `ui/party-games.css`：共用手机布局、卡片与大字展示；继承现有主题变量，包含深色与减少动画适配。
- `index.html`：加载模块，扩展既有导航、返回处理与真心话题库接口。新入口动态加入现有趣味玩法列表，不替换已有玩法。

## 使用方式

数字炸弹默认 1～100，可设置包含至少两个整数的范围（跨度最多一百万、边界绝对值不超过十亿）。猜错后排除已猜数字，猜中后显示爆炸反馈和挑战入口。炸弹只存在内存中，未猜中前不会写入 DOM 或本地存储。

你演我猜默认混合版，将六类 195 个词随机打乱；也可独立选动物、生活、职业、电影、成语或搞笑。表演方式新增默认“语言 + 动作”，仍可选纯动作或语言描述。设置改为卡片选择页，支持 30／60／90／120 秒。删除本地成绩与自定义词库入口，不再保存新成绩；已有数据保留。准备、暂停或退到后台不显示答案，同一轮不重复。

别让我做默认机主一人，不显示参与人数和任务类别，自动混用全部 80 个任务。首页详细说明整体规则、引导示例、任务隐私及朋友交接方式。横竖屏选项保留。“加入未安装 App 的朋友”按钮打开人数选择页，0～9 位朋友不包含机主；例如两位朋友对应三个任务，先朋友 1、朋友 2，机主本人最后。多人第一次展示为全屏 5 秒倒计时，展示完成后后续均为 3 秒；机主独自使用始终为 3 秒。显示按钮前先提示谁应回避，倒计时中不把任务写入 DOM，重复点击不重启计时。后台、取消、退出均停止计时、隐藏任务。每个任务统一以“让 TA …”表达；本局任务不重复。保留横竖屏与成功后的原挑战联动。

记分板提供独立记分和玩家间转移。每场固定一种方式，可选分／元显示（仅本地记账，没有任何支付服务）。每局 2～12 位在场玩家；移除玩家前确认，保留其历史流水和累计。金额以整数百分之一单位存储，显示时才转小数。转移是一笔含两条腿的原子流水，修改、删除、撤销都成对处理。撤销最近一次玩家或流水操作，包含清空；清空本局和删除全部场次均需两次确认。封存场次只读。最多保存 100 场，每场最多 5000 笔，达到限制时提示整理。写入失败不会修改内存中的账目或关闭输入框。

数字炸弹删除猜测记录、结果页的返回玩法列表和修改范围按钮。结果只保留再来一局与“进入真心话大冒险”。进入后展示已有真心话／大冒险选择页，不自动抽题；原说明段落替换为“返回数字炸弹”，直接回到最大值／最小值设置，保留已设范围。不再显示完成挑战、自定义题库等额外按钮。“别让我做”成功后仍可直接抽真心话或大冒险，并按顶部返回键回原任务。

新增 `ui/party-icons.png`：参考原有 `toolkit.png` 生成的四格透明立体卡通图集（紫色、奶油色、薄荷绿及金色），用于菜单和页面标题，不使用输入法表情。

## 数据边界

所有新增持久化数据只使用 `localStorage['hb_party_local_v1']`，包含 `version:1`、`boards`、`results` 和 `custom`。没有使用会通知账号同步的 `save()`，没有加入同步白名单，不修改账号、CloudBase 环境、接口或云端结构。

数字炸弹与任务分配仅在内存中，退出结束。记分场次跨重启保留，旧版猜词成绩、自定义题库数据不删除，与账号无关。清除 App 数据或卸载会删除它们；本次未实现文件导入导出或云端备份。读取异常时保留原始数据并阻止覆盖。手动“清除所有记分场次”只清记分板，不清其他玩法。

## Android 与发布

`MainActivity` 只增加玩法方向桥接及暂停通知；Manifest 声明方向和屏幕变化由 Activity 自行处理，避免旋转重建丢失内存局。没有新增第三方依赖或网络权限。

构建工作流推送 UI 分支后仍执行固定签名构建、验证和上传 Actions 测试产物；预览版发布变为 `workflow_dispatch` 显式勾选 `publish_preview` 才执行，默认 false。本次不发布 GitHub Release，不合并 main。
