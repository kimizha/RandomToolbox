# 账号登录与管理员配置边界

App 的现有邮箱输入框现可接收邮箱或用户名：邮箱使用 CloudBase `signInWithPassword({email,password})`，用户名使用同一 SDK 的 `signInWithPassword({username,password})`。页面不增加管理员入口；密码必须由云端验证，云端拒绝时不会创建本地登录状态。没有在 APK 中保存默认密码、管理员名单或自动会员标志。

云端真实用户需要在 CloudBase 身份认证/用户管理中创建；用户名和密码必须满足该项目认证服务的实际规则。当前会话没有 CloudBase 用户管理能力，因此未创建管理账号。不能用客户端的固定字符串匹配替代账号创建或云端认证。

管理员身份应由受控后端配置到该用户的不可变 UID，不能因输入某个用户名就自动授予权限。未来会员系统需要由服务端统一判断管理员的对应权益；当前项目尚无会员权益接口，本次没有伪造或启用会员资格，也没有变更现有 CloudBase 环境或云端数据结构。

登录成功后沿用 SDK 原有会话恢复与按 UID 的配置同步；密码输入框使用 current-password 自动填充标记，App 不另行明文保存密码。退出登录仍调用云端 signOut。

验证：202 项浏览器检查通过，新增检查覆盖数字用户名转发、邮箱路径保持、密码原样提交及云端拒绝时不登录；请求使用测试替身，未创建真实账号。后台创建账号并授予角色后，仍需实际登录和权限验收。
