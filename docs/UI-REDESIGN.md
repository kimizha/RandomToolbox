# 开心盒 Android UI

独立分支：`ui/android-happybox-redesign`。基线：`312fc6c`（包含个人资料、原始九种动物头像、账号自动同步）。基线之前的 `7987b08` 已有成功 Actions 构建：https://github.com/kimizha/RandomToolbox/actions/runs/41018504467 。最新同步提交通过了离线账号注入与 JS 语法检查；不把此前构建等同于最新提交构建。

## 设计与实现

奶白 / 炭黑底色，薰衣草紫主色，薄荷绿点缀；iOS 风格留白、分组与导航，卡通质感集中于工具插画和既有头像。首页突出用户已有常用与顺序，未收藏时提供明确添加入口。六款工具双列展示，收藏按钮独立于打开按钮。音乐、聚会、工具详情、资料、登录注册与设置保持相同视觉语言。

新增 `app/src/main/assets/ui/happybox.css`、`happybox.js`、`toolkit.png`；修改内置 HTML 布局、账号注入脚本的视觉模板、原生系统栏颜色与返回键处理、Manifest 键盘避让。UI 分支加入现有 APK Actions 推送触发范围，原有自动发布步骤仍仅限原开发分支。

`toolkit.png` 是参考用户提供图片生成的新插画图集。会话参考图没有可读取的本地原始文件，因此没有宣称直接打包用户原图。图集通过 SVG viewBox 显示各图标；导航与操作按钮使用原创线条 SVG。猜拳三种手势使用基于用户提供图片整理的同一张本地素材图集。未替换既有动物头像。

## 保留边界

- `scripts/sync.js` 与动物头像图集原样保留；`scripts/profile.js` 保留原存储键与数据字段，调整头像和昵称的独立保存交互。
- CloudBase 环境、认证接口、云端结构和数据同步逻辑不变。
- 保留 applicationId、数据存储键、用户的常用顺序、转盘/抽签选项、设置、音乐文件与原有登录方式。
- 不修改 main 或既有开发分支。安装升级时仍须使用相同签名；不同签名不能直接覆盖安装，勿为安装而卸载含数据的现有 App。

## 验证

`python3 scripts/check_ui.py`：需要 Python Playwright 与 `/usr/bin/chromium`；在临时副本注入明确的离线占位 key，仅验证 UI，不访问真实认证或云端数据，不修改源 HTML。检查收藏持久化、320/360/390/430px 布局、六工具运行、深色模式、账号各页面与九种头像/资料保存。预览输出于 `docs/ui-preview/`。

另执行 JS/Python 语法检查与 `git diff --check`。未进行真实手机号/邮箱验证码、真实云端同步或 Android 真机测试。浏览器宽度检查不能代替 Android 系统栏与软键盘真机验证。

## 个人资料入口简化

头像右下角增加圆形铅笔按钮，打开系统图片选择器；保留九种默认头像，选中/上传头像后独立自动保存。昵称输入框右侧增加保存按钮，保存昵称后保持页面打开，未保存的昵称不会被头像操作提交或清空。移除底部“从相册上传头像”和“保存资料”按钮。新增 Android 系统图片选择器回调，无需申请整个相册的存储权限；取消选择不改头像。资料仍按原 UID 存储并由既有同步流程处理。

回归覆盖图片上传、头像即时保存、昵称独立保存、空昵称、保存失败、账号变化保护及窄屏/深色布局；相册选择器的 Android 真机交互尚未验证。

## 工具动效和保存反馈

昵称保存成功时在输入框下显示“已保存”（2.4 秒后消失），避免全局 Toast 被资料全屏页遮挡。工具名称统一为“抛硬币”“甩骰子”“猜拳”，内部 ID 和收藏数据保持不变。

`ui/game-pieces.png` 由图像工具参考本轮上传的手势整理生成三种紫色手势；`ui/coin-faces.png` 则参考古币照片生成圆润卡通浮雕的人像正面及胜利女神反面。不是直接将硬币照片贴入界面；保留罗马古币的图案、珠边及厚度，改为浮雕式卡通材质。会话未提供原始附件的本地文件路径，因此手势也是图像工具保留外观后整理的版本，未宣称上传原文件逐像素复用。

硬币采用俯视桌面视角，包含九层边缘、抛起缩放、离地柔影、横向翻面、落地与两次递减回弹；结果仍使用原随机算法。碰撞音使用短噪声瞬态、非整数频率金属共振与低频接触声合成，跟随三次接触时刻触发，服从音量与静音设置。是合成金属音效，不是实录音频。离开工具会取消过期的结果和碰撞触发。

新增检查覆盖三种手势图像解码/显示、硬币两面的最终图像与结果一致、离开页面取消、减少动态效果、离线音频渲染/无削波，以及昵称保存提示的位置与可见性。仍未进行 Android 真机的动效与扬声器听感验收。

本轮验证：86 项浏览器检查全部通过（包含正反面与边缘层居中对齐检查），JS/Python 语法检查与 `git diff --check` 通过；预览新增硬币空中/落地及石头、剪刀、布各状态。
