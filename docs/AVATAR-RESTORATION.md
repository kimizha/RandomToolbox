# 2.9 默认动物头像修补

用户要求保留原来的动物图片，只用 AI 修补边缘，使圆形头像完整自然。

原始素材 `scripts/avatars-sprite.webp.b64` 保持逐字节不变，SHA-256：
`057966ef3c0a0c8516d51725a98ff7b4622e69f0caefe6a742cd13d441400a7d`。

原拼图的圆形边缘、行列分界与三等分 CSS 裁剪并不完全对齐，导致头像出现白色缺角、边缘断裂或邻格背景。现在以原图为参考，使用 AI 分别修补九个头像的背景、轮廓与构图留白，保存为独立副本，保留原动物种类、配色和表情特点。

新增 `app/src/main/assets/ui/avatars-repaired/` 下九张图片：

| 文件 | 原头像 |
| --- | --- |
| wolf.png | 小灰狼 |
| fox.png | 小狐狸 |
| panda.png | 熊猫 |
| cat.png | 小猫 |
| bear.png | 小熊 |
| frog.png | 青蛙 |
| rabbit.png | 兔子 |
| penguin.png | 企鹅 |
| shiba.png | 柴犬 |

`rtApplyAvatar()` 优先使用对应的独立修补图，在圆形区域完整显示；未修改原图作为备用图。背景绘制限制在圆形内容区域内，不侵入选中描边。上传照片仍使用原有显示路径，不经过 AI 处理。

头像 ID、顺序、名称、已保存的选择、个人资料与账号同步字段均不变。没有改动 CloudBase 配置、接口、密码或用户数据结构，也不上传用户的相册照片。

210 项界面回归通过，其中包含九张新图片本地解码、选中立即保存、预览使用修补图、原图备用、昵称保存、上传照片以及浅色／深色窄屏检查；22 个同步场景和 7 项发布逻辑检查通过。预览见 `docs/ui-preview/profile.png` 与 `avatars-repaired-grid.png`。APK 继续由独立 UI 分支构建，不自动发布 Release。
