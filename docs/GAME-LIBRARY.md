## 海龟汤

新增 67 道含悬疑、恐怖氛围的汤，包含现实误会、录音与设备错觉、亡魂、异界和规则类故事等。每题有汤面、确定汤底、三条逐步提示与三条主持人事实。难度总计：入门 25、进阶 38、烧脑 40。

每题选一个生死类型与一个世界观类型：

- 清汤／白汤：没有人死亡；白色背景。
- 红汤：有人死亡，尚有人存活；红色背景。
- 黑汤：故事中的全部人类人物死亡，无人生还；黑色背景。
- 胡辣汤：有人受伤，没有人死亡；橙色背景。
- 本格汤：在现实规则下可能发生；绿色背景。
- 变格汤：现实中不可能发生，依赖超自然等设定；紫色背景。

当前类型覆盖：白汤 58、红汤 20、黑汤 13、胡辣汤 12；本格 72、变格 31。生死标签以本故事涉及人物为范围；本题中出现此前已经离世的人也计入死亡设定。白汤与胡辣汤均无人死亡，已明确受伤的题目使用胡辣汤标签。

开局页可展开全部术语介绍。游戏开始后，汤名旁显示本题的两个彩色标签，点击仅解释这两个类型，不展示其他类型或汤底。标签本身会透露生死与世界观，这是玩法的一部分。主持人查看、揭晓、换题、退出、重开确认和本轮去重规则保持不变。
