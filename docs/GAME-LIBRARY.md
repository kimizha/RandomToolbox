## 海龟汤流程

`ui/soup-game.js` 负责海龟汤页面与本轮状态。沿用聚会玩法登录入口，进入后选择全部/入门/进阶/烧脑难度；题库分别为 12/14/10 道。选一位主持人，其他玩家只读汤面，用提问还原故事。主持人根据参考汤底回答“是／不是／不重要／无法确定”；不是自动生成答案或 AI 裁判。

主持人查看汤底前必须确认交接手机，汤底与关键事实仅在确认后放入主持人弹窗；收起或系统返回会移除弹窗，玩家页面仍不显示答案。“揭晓汤底”另行确认后才在公共页面展示解答。玩家可逐条展开三条提示，全部展开后停止追加。

已揭晓时可直接换下一题；未揭晓换题需确认，取消保留当前题目。抽题在所选难度内排除本轮已出现的 ID，抽完后提示重开，不静默重复。重开需确认，会清除本轮记录并回到难度选择。确认退出后重新进入也开始新一轮；取消退出保留进度。

本轮题目状态只保存在内存，不修改云端数据结构。主持人交接是同一手机上的防误触展示设计；题库本身随 APK 打包，不代表服务端保密题库或付费权益校验。

`ui/soup-turtle.png` 是为海龟汤生成的薄荷绿、紫色卡通海龟插画，保持与现有工具素材一致的色系，未替换动物头像。

## 验证

- `node scripts/check_game_library.cjs` 检查各库数量、提示词/词对/题目 ID 去重、难度覆盖与汤面/汤底/三条提示/事实的完整性。
- `python3 scripts/check_ui.py` 覆盖现有功能与海龟汤完整交互，包括登录入口、交接确认、公共答案隐藏、提示逐条展开、取消/确认揭晓、换题去重、耗尽、重开及明暗窄屏。
- `node scripts/check_sync.cjs`、`python3 scripts/check_release.py` 检查账号同步与发布保护，固定签名 APK 仍由 CI 校验。
- 海龟汤没有访问真实云端数据；真实 Android 交接手机、扬声器与安装体验仍需实机验收。
